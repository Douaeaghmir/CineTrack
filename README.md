## 📌 À propos du projet

**CINATRACK** est une application web de découverte et de consultation de films. Elle offre une interface intuitive permettant aux utilisateurs d'explorer un catalogue de films, de rechercher des titres spécifiques, de filtrer les résultats et de sauvegarder leurs films préférés.

Ce projet a été réalisé dans le cadre de notre formation en développement web afin de mettre en pratique les concepts fondamentaux de JavaScript et de développer une application interactive utilisant une API externe.

## ✨ Fonctionnalités principales

- 🎥 **Affichage des films :** Présentation des films sous forme de cartes avec leurs informations.
- 🔎 **Recherche dynamique :** Recherche de films selon leur titre.
- 🎭 **Filtrage :** Filtrage des films selon différents critères.
- ❤️ **Favoris :** Ajout et suppression de films dans une liste de favoris.
- 💾 **Persistance des données :** Sauvegarde des favoris grâce à localStorage.
- 🌐 **API :** Récupération dynamique des données cinématographiques.
- 📱 **Interface utilisateur :** Interface claire et adaptée à une navigation intuitive.

## 🚀 Installation et lancement

1. Cloner le dépôt GitHub :

```bash
git clone URL_DU_DEPOT
```

2. Accéder au dossier du projet :

```bash
cd CINATRACK
```

3. Ouvrir le projet avec Visual Studio Code.

4. Configurer la clé API si nécessaire.

5. Lancer le fichier `index.html` avec l'extension **Live Server**.

## 💡 Concepts JavaScript mis en pratique

Ce projet nous a permis de travailler sur plusieurs notions essentielles :

- Les fonctions et les tableaux d'objets.
- Les méthodes `map()`, `filter()` et `find()`.
- Les événements JavaScript (`addEventListener`).
- La manipulation du DOM.
- Les fonctions asynchrones (`async/await`).
- Les requêtes HTTP avec `fetch()`.
- Le stockage local avec `localStorage`.
- L'importation et l'exportation avec les modules ES6.

## 🎯 Objectifs pédagogiques

- Développer une application web interactive.
- Apprendre à consommer et exploiter une API externe.
- Organiser le code en modules réutilisables.
- Manipuler et afficher dynamiquement des données.
- Comprendre la persistance des données côté client.
- Améliorer l'expérience utilisateur.
